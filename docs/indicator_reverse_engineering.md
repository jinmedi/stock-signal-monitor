# 유튜브 차트 "단기 지표" 역추적 작업 기록

- 작업일: 2026-10-17

- 질문: 영상에서 말하는 "단기 지표"(골든크로스 언급)가 무엇이며 어떻게 계산된 값인가?

---

## 1. 영상 자체에서 확인한 것

영상 설명란과 고정 댓글에는 종목별 타임스탬프와 멤버십 안내만 있고, 지표의 이름이나 파라미터는 없었다. 차트 화면에도 보조지표 창에 이름이 표시되지 않았다.

화면을 확대해 관찰한 구성은 다음과 같다.

| 영역 | 관찰 내용 | 판단 |
|---|---|---|
| 가격 차트 | 노랑·초록·갈색·빨강·파랑 곡선 | 이동평균선(대략 20·60·120·200일 계열) |
| 가격 차트 | 하늘색 구름, 우측 범례 "전환선 9 / 기준선 26 / 후행스팬 26" | 일목균형표 |
| 보조지표 창 1~3 | 0~100 눈금, 두 선(빨강·파랑)이 교차하며 사이가 음영 처리, 위로 갈수록 파동이 빠름 | 스토캐스틱 슬로우를 단기·중기·장기 3종으로 띄운 구성 |
| 보조지표 창 4 | 주황 선, 25~75 눈금 일부만 보임 | 캡처가 잘려 미식별 |
| HTS UI | 종목변경, 관심지표, 1X1 등 | 키움 영웅문으로 추정 |

차트 우상단의 `LC:57.59 / HC:-13.74` 값은 지표값이 아니라 기간 최저가·최고가 대비 현재가 등락률이었다 (TSM: 420.47/266.82 = +57.59%, 420.47/487.47 = −13.74%).

## 2. 역추적 방법

사용자가 제공한 4장의 고해상도 캡처(Gold, GDXU, TSM 2장) 중 가장 선명한 **TSM 0:59 캡처**를 기준으로 했다.

### 2.1 좌표 보정

- 가로축: 화면의 "282/625"에서 282는 표시 봉 수로 해석했다. 일목균형표 선행스팬이 26봉 앞으로 그려지므로 실제 과거 봉은 256개. 마지막 봉(2026-10-15)의 x=1031px, 첫 봉 x=23px → 봉당 3.95px. 검증: 2025-11-21 최저가 표시 위치(x≈148px)가 계산값(x≈142px)과 일치.
- 세로축: 각 창의 회색 격자선(75, 25) 위치에서 100과 0의 픽셀 위치를 선형 보간. 창1 704→808px, 창2 831→923px, 창3 938.5→1032.5px.

### 2.2 곡선 추출

각 봉 위치의 열(±1px)에서 채도가 있는 픽셀을 모아 y 평균을 0~100 값으로 변환했다. 빨강(R>B) / 파랑(B>R)으로 두 선을 분리했으나, 교차 구간의 음영 색(복숭아색·연하늘색)이 섞여 분리 정밀도는 낮았다. 두 선의 중간값(midline) 기준 비교를 병행했다.

### 2.3 후보 계산과 탐색

- 가격 데이터: Yahoo Finance(yfinance) TSM 일봉 2024-06-01 ~ 2026-10-15.
- 계산식 (스토캐스틱 슬로우, SMA 기반):
  - Fast %K = (C − Lₙ) / (Hₙ − Lₙ) × 100
  - Slow %K = SMA(Fast %K, M)
  - Slow %D = SMA(Slow %K, T)
- 탐색 범위: N = 3~40, M = 1~15, T = 1~15 (총 8,550 조합), 봉 어긋남 ±1 허용.
- 비교 지표: 추출 곡선과 계산 곡선의 RMSE.
- EMA 평활 변형도 함께 계산해 비교.

### 3.4 결론

- 세 창 모두 **스토캐스틱 슬로우(SMA 기반)** 이며, 한국 HTS에서 관행적으로 쓰는 **단기 (5, 3, 3) / 중기 (10, 6, 6) / 장기 (20, 12, 12)** 세트와 일치한다.
- 영상에서 말하는 "단기 지표 골든크로스"는 첫 번째 창(약 5-3-3)의 Slow %K가 Slow %D를 상향 돌파하는 것을 뜻한다.
- 수치상 최적해는 (4,4,3), (8,8,5), (18,15,12) 등 인접 값으로 나왔으나, 픽셀 추출 오차(약 3~5포인트)와 데이터 소스 차이를 감안하면 통용 프리셋과 구분되지 않는다. 신뢰할 수 있는 표현은 "5-3-3 / 10-6-6 / 20-12-12 또는 ±1~2 범위".

## 4. 한계

- 픽셀 추출 오차: 선 두께·안티앨리어싱·음영 색 혼입으로 %K와 %D의 색 분리가 불완전.
- 데이터 차이: 영상 HTS의 10/15 종가 420.47 vs Yahoo 422.25 (고가 423.66, 저가 407.13, 시가 415.17은 일치).
- 빠른 지표(창 1)일수록 극값이 픽셀에 덜 반영되어 평활 파라미터 식별이 어려움.
- 네 번째 보조지표 창은 캡처 범위 밖이라 식별하지 못함.
- 정확한 설정값은 채널에 직접 문의하거나, HTS에 위 세트를 띄워 영상과 겹쳐 확인하는 것이 확실함.

## 6. 재현용 핵심 코드

```python
import yfinance as yf

d = yf.download("TSM", start="2024-06-01", end="2026-10-16", auto_adjust=False)
d.columns = [c[0] for c in d.columns]

def stoch_slow(df, n, m, t):
    lo = df.Low.rolling(n).min()
    hi = df.High.rolling(n).max()
    fast_k = 100 * (df.Close - lo) / (hi - lo)
    slow_k = fast_k.rolling(m).mean()
    slow_d = slow_k.rolling(t).mean()
    return slow_k, slow_d

short_k, short_d = stoch_slow(d, 5, 3, 3)     # 단기
mid_k,   mid_d   = stoch_slow(d, 10, 6, 6)    # 중기
long_k,  long_d  = stoch_slow(d, 20, 12, 12)  # 장기
```
